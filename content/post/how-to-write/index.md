## 发一篇新的

在博客目录下执行：

```bash
hugo new content post/<英文短名>/index.md
```

比如 `hugo new content post/2026-summer-trip/index.md`，会生成一个**文件夹**，
里面有 `index.md`。照片直接丢进这个文件夹，和文章放在一起 —— 这样删文章时图片一起删，
不会在仓库里留下孤儿文件。

新文件头部默认带 `draft: true`（草稿不会发布），写完删掉这行或改成 `false`。

## 本地预览

```bash
hugo server -D
```

浏览器打开 http://localhost:1313 。`-D` 表示连草稿一起显示。
保存文件后页面会自动刷新，不用手动重启。

## 放照片

最常用的写法，图片和 `index.md` 同一个文件夹：

```markdown
![在洱海边](erhai.jpg)
```

方括号里是图片说明（也是无障碍描述），会显示在图片下方。

Hugo 会自动把大图压成多个尺寸，手机上加载小图、电脑上加载大图，
所以**手机原图直接拖进来就行，不用先压缩**。竖拍照片也会按 EXIF 自动转正。

### 设封面

在文章开头的 front matter 里写：

```yaml
image: "cover.jpg"
```

封面会显示在首页卡片和文章顶部。不写就没有，首页卡片会退化成纯文字样式。

## 常用排版

```markdown
## 二级标题        # 一级标题留给文章标题，正文从二级开始

**加粗**、*斜体*、~~删除线~~

> 引用一段话

- 无序列表
- 第二项

1. 有序列表
2. 第二项

[链接文字](https://example.com)

---              # 分隔线
```

## 分类和标签

front matter 里：

```yaml
categories:
    - 旅行
tags:
    - 大理
    - 徒步
```

**分类只填一个**（首页卡片按分类着色，多个会串色），标签随意多个。
分类和标签页面会自动生成，不需要手动建。

常用分类可以先想好几个，比如：日常、旅行、美食、观影读书、想法。
分类少一点更好翻。

## 发布

```bash
git add .
git commit -m "post: 洱海边的三天"
git push
```

推上去之后自动构建部署，一两分钟后线上就更新了。

## 想插视频

B 站视频在播放页点「分享」→「嵌入代码」，把那段 `<iframe>` 直接粘到 Markdown 里就行
（配置里已开启内嵌 HTML）。
